# Mesanube — Design System

> **Hand-maintained.** This file used to be auto-generated by `designlang`; it is now the source of
> truth we edit by hand. It's the compact token + component summary to read before building any new
> component or page. Full details live in `.claude/rules/frontend.md`; canonical CSS vars live in
> `src/app/(frontend)/globals.css`.

The look is **flat, editorial, Argentine**: serif display headings, generous whitespace, a single
olive accent on a white/black/gray canvas. One palette, one accent, no emojis.

---

## Colors

One palette — **olive / black / gray** — with a **single accent** (olive). Reference by CSS var,
never raw hex.

| Token | Value | Usage |
|---|---|---|
| `--heading` | `#000000` | Headings (h1–h3) |
| `--olive` | `#485c11` | **The accent** — eyebrows, links, checkmarks, primary CTA |
| `--olive-dark` | `#3a4c0d` | Primary CTA hover |
| `--olive-soft` | `#dfecc6` | Badges, soft buttons, callout panels |
| `--olive-soft-hover` | `#d0e1ac` | Soft button hover |
| `--olive-tint` | `#f7faf0` | Outline button hover |
| `--body` | `#6f6f6f` | Body / paragraph text |
| `--caption` | `#929292` | Captions, footnotes, step numbers |
| `--divider` | `#e9e9e9` | Section `border-t`, card borders |
| `--surface-dark` | `rgb(36,52,29)` | Dark-green brand panels (Avanzado card, CTA, badges) |
| `--hero-bg` | `#8e9c78` | Hero background |
| `--media-bg` | `#f5f5f0` | Image / media placeholder background |
| `--cream-bg` | `rgb(255,254,252)` | Page / section background |
| `--warm-white` | `rgb(255,247,238)` | Text on dark panels |

**Deprecated** (old "green" system, only `Homepage/*` still uses it, being removed): `--dark-green`,
`--forest-green`, `--medium-green`, `--muted-green`, `--pale-green`, `--light-green-bg`.

**Not the marketing palette:** `--accent` and `--muted` in `globals.css` are shadcn HSL tokens for
the Payload admin. The accent is `--olive`; the muted text is `--caption`.

## Typography

Three families:
- **Headings** → `Crimson Text` serif · `var(--font-crimson)` · `font-display`
- **Body & UI** → `DM Sans` · `var(--font-dm-sans)` · `font-sans`
- **Eyebrows & captions** → `Roboto Mono` · `var(--font-roboto-mono)` · `font-mono`

Type scale (the big headings use explicit `clamp()`; smaller text is fixed `px`):

| Role | Font | Size | Weight | Line-height | Tracking | Color |
|---|---|---|---|---|---|---|
| `h1` (hero) | display | via `HeroHeading` | 400 | tight | — | `--heading` |
| `h2` (section) | display | `clamp(36px, 5.5vw, 60px)` | 400 | `0.9` | `clamp(-1px, -0.2vw, -1.8px)` | `--heading` |
| Card title | sans | `18px` | 700 | `1.4` | `-0.09px` | `--heading` |
| Card title (alt) | display | `18px` | 400 | none | `-0.54px` | `--heading` |
| Eyebrow | mono | `14px` | 400 | `1.4` | `-0.14px` (`uppercase` on feature pages) | `--olive` |
| Body | sans | `18px` | 400 | `1.4` | `-0.09px` | `--body` |
| Quote | display | `clamp(24px, 3vw, 40px)` | 400 | `1`–`1.1` | tight | `--heading` |
| Caption / footnote | mono | `14px` | 400 | `1.4` | `-0.14px` | `--caption` |

## Spacing & layout

- Max content width: **1500px** · horizontal page padding: `px-4 sm:px-6 lg:px-10`
- Section rhythm: top divider + `pt-[60px] pb-[80px] sm:pt-[80px] lg:pb-[120px]`
- Cards: `border-t border-[var(--divider)] py-[40px]`
- Radii: cards/media `rounded-[20px]` (`lg:rounded-[30px]` on `/para/*` hero/media); pills `rounded-full`

## Motion

- Easing `cubic-bezier(0.22, 1, 0.36, 1)` · reveal `900ms` · image zoom `1200ms`
- Scroll reveal: wrap in `<Reveal>` → `.reveal` → `.reveal.is-visible` (IntersectionObserver, 15%)
- Stagger: `delay={1..4}` → `.reveal-delay-1..4` (80–320ms)

## Buttons & CTAs

- `TrialButton` / `DemoButton` — dialog-opening trial/demo CTAs (client) · `DemoLink` — underline variant
- `CtaLink` (`shared/CtaLink`) — pill link for anchors/external links: `primary` (olive + arrow),
  `soft` (pale olive), `outline` (bordered white). Replaces per-page `PrimaryButton`/`SoftButton`.

## Page templates & component collections

Marketing pages are **data + composition** — never inline section markup. Two templates, two
collections (pick by idiom). Full component tables in `.claude/rules/frontend.md §6`.

- **`components/feature/`** — feature/detail pages (`/funciones/*`): 22px nav, **UPPERCASE** eyebrow,
  two-column sections, 3-up numbered steps, compact pricing, two-column CTA.
- **`components/usecase/`** — use-case pages (`/para/*`) + the funciones index: 26/30px nav,
  **sentence-case** eyebrow, stacked headers, centered CTA.

One-off sections are written inline **with tokens** (not a new component). Duplicated inline markup
is not allowed.

## Do's and Don'ts

**Do**
- Sentence-case, tight headings; address the reader as "vos" (voseo).
- Reference local context: ARCA (not AFIP), pesos, Argentina.
- Reuse tokens and the section collections; keep the flat material (radius + subtle shadow habits).

**Don't**
- No raw hex, no deprecated green vars, no legacy green `shared/` primitives.
- **No emojis** in copy or as decorative icons (the functional `✓` and `→` are fine).
- No inline static `style={{}}`, no `!important`, no `px` font sizes below the type scale.
- Don't hardcode prices — interpolate from `src/config/plans.ts`.
