Si cobraste un pedido con un descuento de más o con el medio de pago equivocado, lo corregís sin reabrirlo. El pedido sigue **Cobrado** y queda registrado quién hizo la corrección.

## Antes de empezar

- Pueden corregir **Cajero**, **Encargado** y **Dueño**.
- El turno de caja en el que se cobró el pedido tiene que seguir abierto. Con el turno cerrado, el sistema no deja corregir.
- No se pueden cambiar los items ni las cantidades de un pedido cobrado.

## Pasos

### Para quitar el descuento

1. Abrí el pedido **Cobrado**.
2. En el renglón **Descuento**, tocá el ícono del tacho.
3. En el aviso **Quitar descuento**, confirmá con **Quitar descuento**.

El total se recalcula y el pedido sigue cobrado. Un descuento quitado de un pedido cobrado no se puede volver a aplicar.

### Para cambiar el medio de pago

1. Abrí el pedido **Cobrado**.
2. Tocá el ícono del lápiz, al lado de **Medio de pago**.
3. En **Nuevo medio de pago**, elegí el medio correcto.
4. Tocá **Confirmar cambio de medio**.

El medio se reemplaza y el total no cambia.

> **Importante:** si el pedido ya tiene una factura emitida, no se puede quitar el descuento. Para corregir una factura hace falta una nota de crédito. Con factura emitida sí podés cambiar el medio de pago entre medios comunes.

## Problemas frecuentes

### No aparece el ícono del lápiz
El pedido tiene que estar cobrado, y tu rol tiene que ser cajero, encargado o dueño.

### El ticket que se le dio al cliente ya no coincide
La corrección se hace en el sistema. Si hace falta, reimprimí el ticket.

### Necesito pasar el pedido a Consumo interno, o sacarlo
Es un caso aparte, porque cambia el total del pedido. Mirá [cómo pasar un pedido cobrado a Consumo interno](/soporte/pedidos/pasar-un-pedido-cobrado-a-consumo-interno).

### Quiero quitar un descuento de un pedido sin cobrar
Se hace desde el mismo ícono del tacho, o con **Modificar descuento**. El cajero necesita la aprobación de un encargado. Ver [cómo aplicar un descuento](/soporte/pedidos/aplicar-un-descuento).
